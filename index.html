Наведение на карточку

Карточка становится непрозрачной, получает тень. В левом верхнем углу появляется действие скрытия.

180msease: .2 .8 .2 1bg → #FFF

Глаз → «Скрыть»

При наведении контрол раскрывается вправо от фиксированного anchor. Левая точка не прыгает.

24×24 → 55×26translateX: 4px180ms

Скрытие уведомления

По клику карточка уходит через fade + scale и удаляется из layout.

500msscale: 1 → .86y: 0 → -4

Обрезание длинного текста

Без троеточия. Последняя часть строки растворяется в fade, текст остается визуально мягким.

fade-point: 85.065%15/20no ellipsis

Механика правой панели

Поведение стека уведомлений и вспомогательных контролов.

Наведение на событие

Скрываемые карточки получают белый фон, тень и глазик. Для alert-карточек и синих action-карточек контрол скрытия не рендерится.

180msbg → #FFFeye: 24×24

Глаз → «Скрыть»

Только у скрываемых событий контрол раскрывается вправо до 55×26 px, не сдвигая исходную точку привязки.

24×24 → 55×26translateX: 4px180ms

Приоритет отображения

Нескрываемые уведомления всегда резервируют верх стека. Сначала красные alert-события, затем синие action-required, после них остальные скрываемые уведомления.

1 alert2 action3 other

Правило скрываемости

Красные alert-уведомления и синие уведомления, требующие действия, скрывать нельзя. У них нет глазика и действия «Скрыть». Остальные события можно скрывать.

red → no hideblue action → no hideother → hide

Удаление из стека

Скрываемая карточка исчезает. Все элементы ниже занимают освободившееся место одним движением.

FLIP500msexpressive

«Все уведомления»

Без каунтера кнопка сжимается по ширине текста. При появлении badge ширина увеличивается по контенту. Hover меняет только фон.

width: autoh: 32pxbadge: 16×16

Каунтер скрытых

Считает только карточки, не поместившиеся по высоте. Принудительно скрытые через «Скрыть» в число не входят. При значении 0 badge не показывается, отсчёт начинается с 1. Цифра меняется вертикальным reel: slide + fade + лёгкий blur.

overflow only220msreel + blur

Появление нового уведомления / PTR

PTR имитирует пользовательскую перезагрузку страницы. После обновления актуального списка может прийти новое уведомление: существующие карточки съезжают вниз, новая появляется сверху через fade + scale. Это не системная кнопка «Перезагрузить» стенда.

500msfade + scaleshift ↓

Лимит отображения

Высота колонки измеряется фактически, без жестких брейкпоинтов по количеству карточек. Во вьюпорте может одновременно находиться до 6 уведомлений: максимум 4 события и 2 пуша. Показываются только полностью помещающиеся карточки. CTA «Все уведомления» всегда идет сразу после списка уведомлений. Между CTA и карточкой «Документы» постоянно резервируется 32 px.

total: 64 events + 2 pushCTA → Docs: 32pxResizeObserver
