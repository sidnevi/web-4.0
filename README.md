# web-4.0

Статический стенд с двумя прототипами: одиночная нотификация и правая панель
со стеком уведомлений. Открывается двойным кликом по `index.html` — сборка
не нужна.

## Структура

- `index.html` — разметка обоих экранов и спека справа
- `styles.css` — токены и стили
- `app.js` — переключение вкладок, скрытие карточек, FLIP-анимации,
  пересчёт лимита по высоте колонки
- `assets/` — иконки SVG

## Стенд

- вкладки сверху переключают прототипы, «Перезагрузить» сбрасывает состояние
- слева на вкладке «Правая панель» — высота колонки, добавление нотификации и PTR
- справа — параметры анимаций, кнопка рядом с пунктом копирует их в буфер
